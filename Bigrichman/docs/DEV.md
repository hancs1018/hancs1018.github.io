# 像素大富翁 · 开发文档

> 项目类型：本地多人像素风大富翁（网页版）
> 技术栈：原生 HTML + CSS + JavaScript（无框架、无后端、双击即玩）
> 目标：2~4 人同屏轮流游戏，纯浏览器运行

---

## 1. 项目概述

### 1.1 核心玩法
经典大富翁回合制桌游：玩家轮流掷骰子沿环形棋盘移动，购买地皮、收取过路费、触发机会卡事件，资金归零破产，最后存活的玩家获胜。

### 1.2 设计风格
- **像素风（Pixel Art / 8-bit）**：像素字体、CSS 像素化渲染（`image-rendering: pixelated`）、8-bit 配色
- **配色方案**：深色背景 + 高饱和点缀色（紫 `#7b2ff7`、青 `#00d9c0`、橙 `#ff9f1c`、黄 `#ffd60a`）
- **字体**：Google Fonts "Press Start 2P"（英文像素）+ 系统像素字体 fallback

### 1.3 运行方式
纯静态文件，无需构建、无需服务器，双击 `index.html` 即可游玩。

## 3. 游戏规则设计

### 3.1 基础参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 玩家数量 | 2~4 人 | 开局界面选择，输入昵称 |
| 初始资金 | ¥15000 | 每位玩家 |
| 经过起点奖励 | ¥2000 | 完整经过/停留在起点格 |
| 骰子 | 2 个六面骰（2~12） | 掷出相同点数可再掷一次（可选规则） |
| 破产条件 | 资金 < 0 且无可变卖资产 | 该玩家出局，其地皮回归无主 |

### 3.2 棋盘格子（32 格环形，8 格/边）

| 类型 | 数量 | 说明 |
|------|------|------|
| 🏁 起点 | 1 | 经过发工资 ¥2000 |
| 🏠 地皮 | 20 | 5 个色系地块组（棕/浅蓝/粉/橙/红），每组 3~5 块，可购买、升级 |
| ❓ 机会卡 | 4 | 随机事件：奖励/罚款/移动/免过路费等 |
| 🛒 道具店 | 2 | 可购买道具（如"免过路费卡"、"双倍租金卡"，可选功能） |
| 💸 缴税格 | 2 | 支付固定金额（¥1000 / ¥2000） |
| 🚔 监狱 | 2 | 停留 1 回合（或支付 ¥500 提前离开） |
| 🅿️ 免费停车 | 1 | 安全格，无效果 |

### 3.3 地皮经济模型

| 色系 | 地价 | 基础过路费 | 升级费用/级 | 每级过路费倍率 |
|------|------|-----------|------------|--------------|
| 棕色 | ¥600 | ¥60 | ¥500 | ×2 |
| 浅蓝 | ¥1000 | ¥100 | ¥500 | ×2 |
| 粉色 | ¥1400 | ¥140 | ¥1000 | ×2 |
| 橙色 | ¥1800 | ¥180 | ¥1000 | ×2 |
| 红色 | ¥2200 | ¥220 | ¥1500 | ×2 |

- 地皮最多升级 3 次（小房子 → 中房子 → 大别墅）
- 集齐同一色系全部地皮后，过路费额外 ×1.5（可选规则）

### 3.4 机会卡事件池（示例）

| 事件 | 效果 |
|------|------|
| 银行分红 | 获得 ¥1000 |
| 税务稽查 | 支付 ¥800 |
| 天降横财 | 获得 ¥2000 |
| 房屋维修 | 每有一级升级支付 ¥300 |
| 前进 3 格 | 立即移动，触发落点效果 |
| 回到起点 | 移动至起点并领取 ¥2000 |
| 免过路费卡 | 获得道具，下次免付过路费 |
| 全体收租 | 其他玩家各支付你 ¥500 |

## 4. 技术设计

### 4.1 核心数据结构

```js
// 格子定义（board.js）
const tile = {
  id: 0,
  name: "起点",
  type: "start",           // start / property / chance / shop / tax / jail / parking
  // 仅 property 类型有：
  colorGroup: "brown",
  price: 600,
  baseRent: 60,
  upgradeCost: 500,
  owner: null,             // 玩家索引 或 null
  level: 0                 // 0~3 升级等级
};

// 玩家定义（players.js）
const player = {
  id: 0,
  name: "玩家1",
  color: "#ff0055",        // 棋子颜色
  money: 15000,
  position: 0,             // 棋盘格索引
  properties: [],          // 拥有的地皮 id 列表
  items: [],               // 道具列表
  inJail: 0,               // 剩余监禁回合数，0 = 自由
  bankrupt: false
};
```

### 4.2 游戏状态机（game.js）

```
IDLE（等待掷骰）
  → ROLLING（骰子动画中）
  → MOVING（棋子逐格移动动画）
  → LANDED（触发落点效果）
    ├─ 空地皮 → 询问是否购买 → BUY / SKIP
    ├─ 他人地皮 → 自动支付过路费
    ├─ 机会卡 → 弹窗展示事件结果
    ├─ 监狱 → 标记 inJail
    └─ ...其他格子
  → CHECK_BANKRUPT（破产判定）
  → NEXT_TURN（切换到下一位玩家）
  → GAME_OVER（仅剩 1 人）
```

### 4.3 棋盘渲染方案

**方案：CSS Grid 环形布局（推荐）**
- 棋盘容器使用 `display: grid`，32 个格子按环形顺序绝对定位（上 9 / 右 7 / 下 9 / 左 7，四角格更大）
- 棋子用绝对定位的小方块，通过 JS 计算目标格子的屏幕坐标做平滑移动动画（CSS `transition` 或 `requestAnimationFrame`）
- 每个格子是纯 DOM 元素，便于 hover 显示详情 tooltip

**优点**：无需 Canvas，响应式容易，事件绑定简单。

### 4.4 像素风实现要点

```css
/* 全局像素化 */
* { image-rendering: pixelated; }

/* 像素字体 */
@import url('https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap');
body { font-family: 'Press Start 2P', 'Zpix', monospace; }

/* 像素边框（box-shadow 模拟硬边） */
.pixel-border {
  border: 4px solid #000;
  box-shadow: 
    inset -4px -4px 0 0 rgba(0,0,0,0.3),
    4px 4px 0 0 rgba(0,0,0,0.5);
  border-radius: 0; /* 禁止圆角 */
}

/* 像素按钮 */
.pixel-btn {
  background: #7b2ff7;
  color: #fff;
  border: 3px solid #000;
  box-shadow: 0 4px 0 #3d1478;
  cursor: pointer;
  text-transform: uppercase;
}
.pixel-btn:active {
  transform: translateY(4px);
  box-shadow: 0 0 0 #3d1478;
}
```

### 4.5 骰子动画
- 两个六面骰，用 CSS 绘制骰面（grid 排布圆点）
- 掷骰时快速切换随机面 10~15 帧（每 50ms 一帧），最后定格到结果面
- 可选：轻微旋转 + 弹跳 CSS 动画

### 4.6 移动动画
- 棋子逐格移动：每格 200ms，`transition: top/left` 平滑过渡
- 移动经过起点时立即触发发工资

## 7. 关键实现细节备忘

1. **经过起点判定**：移动完成后比较 `oldPosition > newPosition`（取模回绕）即说明经过了起点
2. **过路费计算**：`baseRent * 2^level`，若触发同色系加成再 ×1.5
3. **破产清算**：玩家破产时将其所有地皮 `owner = null, level = 0` 重置为无主
4. **回合跳过**：`inJail > 0` 或 `bankrupt = true` 的玩家直接跳过
5. **动画队列**：用 `async/await` + `setTimeout` Promise 化串行动画，避免状态错乱
6. **日志系统**：所有事件（掷骰、购买、支付）追加到日志面板，自动滚动到底部
7. **防呆设计**：资金不足时禁用购买按钮；非当前回合禁用所有操作
